# Настройка подписанных URL для медиа-файлов

## Добавление секрета MEDIA_SIGNING_SECRET

Для работы системы подписанных URL необходимо добавить секрет `MEDIA_SIGNING_SECRET` в оба worker'а.

### Генерация секрета

Сгенерируйте случайный секрет (рекомендуется 32+ байта):

```bash
openssl rand -hex 32
```

Или используйте любой другой способ генерации криптографически стойкого случайного значения.

### Добавление секрета в home-courses

```bash
cd apps/web/apps/home-courses
wrangler secret put MEDIA_SIGNING_SECRET
```

Введите значение секрета, когда будет запрошено.

### Добавление секрета в home-courses-media

```bash
cd apps/web/apps/home-courses-media
wrangler secret put MEDIA_SIGNING_SECRET
```

**Важно:** Используйте **тот же самый секрет** в обоих worker'ах!

### Проверка

После добавления секретов:

1. Убедитесь, что Cloudflare Access настроен только на `home-courses.workers.dev`
2. Убедитесь, что `home-courses-media.workers.dev` **не** защищен Access
3. Зайдите на сайт и откройте урок с видео
4. Проверьте в DevTools:
   - Запросы к `/api/media-url` возвращают подписанные URL
   - Видео загружается напрямую с `home-courses-media`
   - URL содержат параметры `?exp=...&sig=...`
   - Нет ошибок 403 при загрузке медиа

## Отключение проверки подписи (для разработки)

Если нужно временно отключить проверку подписи в `home-courses-media` (например, для локальной разработки), можно просто не добавлять секрет `MEDIA_SIGNING_SECRET` в этот worker. В этом случае проверка подписи будет пропущена.

**Внимание:** Не используйте это в продакшене!
