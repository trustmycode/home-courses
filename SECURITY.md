# Политика безопасности

## Поддерживаемая версия

Исправления безопасности выпускаются для текущей ветки `main`.

## Как сообщить об уязвимости

Не создавайте общедоступную задачу с описанием уязвимости, секретами или личными данными. Используйте закрытое сообщение через раздел **Безопасность → Рекомендации → Новая черновая рекомендация** этого репозитория.

Укажите затронутую версию, способ воспроизведения, возможное влияние и предлагаемый способ проверки исправления. Не прикладывайте действующие ключи Cloudflare, содержимое боевой D1 или закрытые материалы R2.

Получение сообщения и дальнейший порядок действий будут подтверждены в закрытом уведомлении GitHub.
