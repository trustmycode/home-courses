# Веб-приложение домашних курсов

Это приложение Next.js для закрытого каталога курсов. Общая архитектура, настройка Cloudflare, порядок миграций и публикации описаны в корневом [`README.md`](../../README.md).

## Локальная проверка

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm build
```

Для локального входа явно задайте `DEV_USER_ID` и `DEV_USER_EMAIL`. Боевые `D1` и `R2` в окружении разработки не подключаются как удалённые.

Публикация требует настроенных `CF_ACCESS_TEAM_DOMAIN`, `CF_ACCESS_AUD` и секрета `MEDIA_INTERNAL_TOKEN`. Значения секретов не хранятся в репозитории.
